# MagicBall 🎱

**MagicBall** - это мобильное Android-приложение «Шар предсказаний».
Пользователь выбирает режим, задаёт вопрос и получает случайный ответ.

Проект реализован на **Kotlin** - современном языке программирования для Android.
Интерфейс полностью создан с помощью **Jetpack Compose** - это новый способ разрабатывать экран приложения прямо в коде, без отдельной разметки.

Для внешнего вида используется **Material3** - библиотека от Google, которая задаёт современный стиль кнопок, текста, карточек и других элементов интерфейса.

---

## 📱 О приложении

Приложение состоит из нескольких экранов (режимов), между которыми пользователь может переключаться.

Интерфейс выполнен в тёмной теме с градиентным фоном.
Основной акцент сделан на минимализме, аккуратных отступах и плавных скруглениях элементов.

Взаимодействие максимально простое:

1. Пользователь выбирает режим
2. Выполняет действие (вводит варианты / нажимает кнопку)
3. Получает результат на экране

---

## ⚙️ Реализованные режимы

### 1. Классический режим

В этом режиме приложение выдаёт случайный ответ из встроенного набора.

Логика простая:

* внутри приложения есть список стандартных фраз
* при нажатии кнопки выполняется случайный выбор
* выбранный ответ отображается на экране

Генерация ответа происходит непосредственно в приложении.

---

### 2. Свои варианты

Этот режим позволяет пользователю вводить собственные варианты ответа.

Принцип работы:

* пользователь вводит текст
* приложение использует введённые варианты для генерации случайного ответа

Ответ выбирается случайным образом из введённых данных.

---

### 3. Совет на день

Этот режим получает данные через интернет.

При запуске:

* приложение отправляет запрос к публичному API
* сервер возвращает случайную цитату
* цитата отображается на экране

Для выполнения сетевого запроса используется библиотека Retrofit.

Каждый раз при обращении к режиму выполняется новый запрос.

## 🛠 Технологический стек

**Kotlin** - основной язык разработки, на котором реализована вся логика приложения.

**Jetpack Compose** - инструмент для создания интерфейса напрямую в коде, без отдельной разметки экранов.

**Material3** - библиотека компонентов и стилей от Google, отвечающая за современный внешний вид приложения.

**Retrofit** - библиотека для выполнения сетевых запросов и получения данных из API.

**Coroutines** - механизм для выполнения фоновых операций без зависания интерфейса.

**Git / GitHub** - система контроля версий и хранения проекта.

## 🚀 Запуск проекта

1. Установить **Android Studio**.
2. Скачать проект с GitHub (ZIP или git clone).
3. Открыть папку проекта в Android Studio.
4. Дождаться завершения Gradle Sync (автоматическая загрузка и настройка всех зависимостей проекта).
5. Запустить приложение на эмуляторе или физическом устройстве через кнопку **Run ▶**.

Для работы режима «Совет на день» требуется подключение к интернету.
