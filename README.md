# MagicBall 🎱

Мобильное Android-приложение «Шар предсказаний», разработанное на Kotlin с использованием Jetpack Compose.

## 📱 Описание

Приложение реализует три режима работы:

1. **Классический режим**  
   Возвращает стандартные ответы:  
   "Да", "Нет", "Возможно" и т.д.

2. **Свои варианты ответа**  
   Пользователь может ввести собственные варианты,  
   которые сохраняются в локальную базу данных (Room).

3. **Предсказание на день**  
   Получение случайной цитаты через публичное API (Retrofit).

---

## 🛠 Используемые технологии

- Kotlin
- Jetpack Compose
- Room (локальная база данных)
- Retrofit (работа с API)
- Git / GitHub

---

## 💾 База данных

Используется Room для хранения пользовательских вариантов ответов.

---

## 🌐 API

Для получения цитат используется публичное API с помощью Retrofit.

---

1. Открыть проект в Android Studio
